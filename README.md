# Python & Pandas Data Analysis

## Overview
This project demonstrates fundamental data analysis techniques using Python and Pandas on Advertising and Salaries datasets.

## Technologies
- Python
- Pandas
- NumPy
- Google Colab

## Key Features
- Load and inspect CSV datasets
- Explore rows, columns, shape, and data types
- Check and handle missing values
- Filter salary records using conditions
- Calculate descriptive statistics
- Create an updated sales column with a 10% increase

## Files
- `untitled7.py` — Python data analysis exercises
- `Advertising.csv` — Required advertising dataset
- `Salaries.csv` — Required salary dataset

## How to Run
Install the required libraries:

```bash
pip install pandas numpy
```

Place the required CSV files in the same directory as the Python script, then run:

```bash
python untitled7.py
```

## Learning Outcomes
Python programming, data manipulation, data cleaning, exploratory data analysis, and descriptive statistics.
